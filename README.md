# РАНГ АВТО — сайт компании

Адаптивная главная страница для компании по подбору и импорту автомобилей из Японии, Южной Кореи и Китая.

## Состав проекта

- `index.html` — структура страницы, текст, формы и SEO-метаданные.
- `styles.css` — оформление, адаптивная сетка, мобильное меню, состояния элементов.
- `script.js` — мобильная навигация, переключение страны и демонстрационная форма заявки.

## Как посмотреть

Откройте `index.html` в браузере. Для разработки удобнее использовать расширение Live Server в VS Code или любой локальный HTTP-сервер. Сборка и установка npm-пакетов не требуются.

## Что уже работает

- Навигация по разделам страницы.
- Мобильное меню и адаптация под небольшие экраны.
- Выбор направления импорта в форме.
- Сбор параметров заявки и копирование текста в буфер обмена.
- FAQ на нативном `details/summary`.
- Ссылки из карточек стран автоматически выбирают соответствующую страну в форме.

## Что нужно сделать до публикации

1. Заменить демонстрационную фотографию на согласованный снимок автомобиля / собственные материалы компании.
2. Уточнить юридическое название, контакты, регионы работы и фактические условия импорта.
3. Подключить отправку формы к выбранному каналу: CRM, серверный обработчик или подтверждённый рабочий email. Сейчас форма ничего не отправляет на сервер и не собирает контакты клиента.
4. Добавить политику обработки персональных данных и согласие на обработку данных, если они будут собираться.
5. Проверить тексты, изображения, доступность и работу на мобильных устройствах.
6. Настроить домен и HTTPS после выбора способа размещения.

## Принцип контента

Сроки, стоимость, количество доставленных автомобилей, гарантии и другие коммерческие обещания не указаны как подтверждённые факты. Добавляйте их только после согласования с компанией.

## Публикация

Это статический сайт, поэтому его можно разместить на статическом хостинге. Перед подключением домена выберите площадку, проверьте настройки приватности репозитория и убедитесь, что сайт не содержит ключей, паролей или закрытых данных.
